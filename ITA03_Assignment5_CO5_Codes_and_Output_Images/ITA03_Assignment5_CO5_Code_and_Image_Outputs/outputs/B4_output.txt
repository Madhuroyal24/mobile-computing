CHALLENGE INPUT
Fast Wi-Fi + flagship CPU + 16% battery: the rule selects 480p because low battery is a hard constraint.
A rule based only on CPU/network would choose 1080p and could consume too much energy.

DECISION NOTE
Use this bounded heuristic for quick on-device decisions; it does not guarantee global minimum energy.
Exhaustive search is suitable for offline tuning of a small device-profile set, not per-upload decisions at scale.
Monitor encode time, upload completion, battery change, thermal state, bitrate, frame drops and failures.

Note: Energy and battery values are illustrative model estimates, not measured phone telemetry.
